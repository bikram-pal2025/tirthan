# 🛕 Tirthan - Temple Heritage & Pilgrimage Portal

A modern, fully responsive Temple Heritage & Pilgrimage Portal built using **React.js**, **Tailwind CSS**, and **Vite**. The website helps users explore famous temples across India with detailed information, search and filter functionality, image galleries, and Google Maps integration.

---

## 🌐 Live Demo

**Live Website:**  
https://tirthan-gamma.vercel.app

**GitHub Repository:**

## 📖 Project Overview

Tirthan is a frontend web application designed to provide information about India's famous temples and pilgrimage destinations. The project focuses on a clean UI, responsive design, and an easy-to-use interface for discovering temples based on different categories.

---

## ✨ Features

- 📱 Fully Responsive Design
- 🔍 Search Temples by Name
- 🗺️ Google Maps Location Links
- 🏛️ Temple Details Page
- 🖼️ Temple Image Gallery
- ⚡ Fast Performance with Vite
- 🎨 Modern UI using Tailwind CSS
- 🧭 Smooth Navigation
- 📍 Heritage and Pilgrimage Information

## 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/bikram-pal2025/tirthan.git
```

Go to the project directory:

```bash
cd tirthan
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
